# ⚽ Fantasy Premier League (FPL) AI Predictor

## 📌 About The Project
This is a Machine Learning web application that predicts the total points a player might score in the Fantasy Premier League (FPL). The prediction is based on historical player stats such as minutes played, goals, assists, clean sheets, and opponent difficulty.

## 🚀 Features
- **AI Point Prediction:** Uses a trained Machine Learning model (Random Forest/Gradient Boosting) to forecast FPL points.
- **Interactive UI:** Built with Streamlit for a user-friendly, real-time prediction experience.
- **Custom Player Scenarios:** Users can input custom match scenarios (e.g., 90 mins played, 1 goal, home match) to see how many points a player would get.

## 🛠️ Built With
- **Python** 
- **Scikit-Learn** (for Machine Learning)
- **Pandas & NumPy** (for Data Processing)
- **Streamlit** (for Web Frontend)
